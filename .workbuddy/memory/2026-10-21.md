  · 列宽 35fr/65fr → **38fr/62fr**；`.modal__left` 加 `overflow-y:auto`、地图卡 `min-height:240px`。
  · 备注口径：`ref.desc` → 没有就取最近一张带 `remark` 的照片（现有数据 0 个 desc、仅 1 条媒体备注，靠后者才有内容）。
- **右栏时间轴**：`renderContent` 先把 list 按 `takenAt` 升序排好（灯箱序号跟着视觉顺序），再 `buildTimeline` 分组。每组 = 40px 竖轴（圆点 + 贯穿线，最后一组线只画 16px 收口）+ 日期头（`MM.DD 周X · N 张`）+ 当日 `.mgrid`；顶部 `.tl__range` 显示 `YYYY.MM.DD – YYYY.MM.DD · N 天 · M 项`（单日显示"当天"）；跨天空档 ≥2 天插 `.tl__gap`「间隔 N 天」；无 `takenAt` 的沉底成"未标注日期"。常规弹窗只保留日期头、隐藏竖轴（`.tl__rail`）。
  · 坑：`formatDateDot()` 内部 `parseDate()` 只吃字符串，**不能直接传 Date**（会返回空串）——先 `dayKeyOf(d)` 转 `YYYY-MM-DD`。EXIF 的 `2016:02:02 10:00:00` 格式也要先规整成 ISO 才能 `new Date()`。
- **地图照片点位**（**仅全屏**）：带 GPS 的照片按经纬度 2 位小数（≈1km）去重 → 再按投影后 <44px 合并成簇（右下角 `.phpin__n` 标数量）→ 最多 8 簇；右下角胶囊「N 张照片」可一键收显（`photoDotsOn` 跨地点记忆）。全屏取景：地点离拍摄点 ≤5km 就把两者一起 `fitBounds`，更远只框拍摄点（黄龙的标记坐标离实际拍摄点 28km，两者同框会把点位挤成一坨）。常规态**不画点位也不显示胶囊**——320px 地图里点位多半在视野外，只会出现"写着 69 张照片却一个点都没有"。
- 顺手补的空状态：`renderContent` 无媒体时渲染 `.modal__empty`（"这里还没有照片" + 添加媒体按钮），否则右栏是一片纯白像没加载出来。
