## Docker Hub 多架构镜像推送 · 跑通
- `.dockerignore` 补排除 `minio-data`（95MB/497 文件）与 `preview/`，避免构建上下文白传；Dockerfile 本就只 COPY 必要文件，镜像内容不受影响。
- 绕了一大圈后跑通：buildx 直推 Docker Hub 在 Mac+代理下不可行（`--driver-opt env.HTTP_PROXY` 无法注入 docker-container builder 的 buildkitd，拉基础镜像仍直连投毒 IP）。最终用**守护进程**路线：`docker buildx use default` → `docker build --platform linux/amd64/arm64` 各建一次 → `docker push` → `docker buildx imagetools create` 合成多架构。
- 产物：`wyc6036/travelmap:v3` 与 `:latest` 均为 amd64+arm64 OCI index（digest 同为 sha256:2171a540…）。完整踩坑与命令已写入 MEMORY.md「Docker / 部署」。
- 中间 tag `v3-amd64`/`v3-arm64` 可从 Docker Hub 网页 Tags 删除（v3/latest 按 digest 引用底层 blob，删 tag 不影响）。
