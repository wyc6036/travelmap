## 记录页滚动卡顿 + 筛选条优化（已完成）
- **根因**：网格 `mediaThumb` 一直返回 `item.url`（server 生成的 1600px 全图），而后端其实已生成 720px 缩略图 `thumb_url`（server.js 上传时 `addMedia({thumb_url})` 已落库），只是 `data.js` 的 `normalizeMediaItem` 没透传、前端也没接。150 张全图同时解码+下载 → 滚动白屏/卡顿。
- **修复**：① `data.js` 透传 `thumb_url`；② `ui.js` 的 `mediaThumb` 改为优先 `item.thumb_url || item.url`，地点卡封面 `realCover` 也优先 `thumb_url`；③ 灯箱主图仍用 `item.url`（全图，正确），灯箱底部缩略图条改用 `thumb_url`；④ `.coll-group` 加 `content-visibility:auto` + `contain-intrinsic-size`，跳过屏外分组的布局/绘制。老数据（无 thumb_url）自动回退全图，不破图。
- **筛选条（#tm-coll-filter）随滚动上移、但常驻 sticky 用户嫌丑**：改为「滚动感知」——默认融入页面（透明、`position:sticky;top:0` 但无背景），仅当 `scrollTop>4` 时加 `.is-stuck` 浮现毛玻璃（`backdrop-filter:blur(12px)` + 轻阴影 + 背景出血到边缘），停滚回到顶部即恢复透明。滚动监听挂在 `#tm-scroll`（passive）。
- 改动文件：`web/js/data.js`、`web/js/ui.js`、`web/js/detail-modal.js`、`web/css/components.css`；均通过 node --check。注意 8099 测试数据是占位种子（无 thumb_url），生产真实上传的媒体才带 thumb_url，故端到端需 Docker 环境 rebuild。

### 筛选条改为「常驻 + ScrollEdgeEffect 模糊」（用户反馈后修订）
- 用户反馈：滚动后那层毛玻璃发白、边缘生硬，像白色涂抹（附截图）；要求**保持常驻**，但效果要复刻「地点详情弹窗中地图与媒体之间」那层模糊。
- 弹窗那层实现在 `modal.css`：`.modal__mapblur`（`backdrop-filter: blur(var(--mw-blur))` + 上下 `mask-image` 渐变让越靠内容越糊）+ `.modal__mapedge`（白色向下渐隐消硬边）；由 `detail-modal.js` 的 `syncScrollEffect` 把 `p=scrollTop/距离` 写进 `--mw-blur/--mw-p`（`rafThrottle` 一帧一次）。
- 修订方案：`#tm-coll-filter` 恒 `position:sticky;top:0`（常驻）；玻璃带放 **`::before`**（`z-index:-1` 垫到 chips 之下，父级 `z-index:6` 已建层叠上下文，不越界），`opacity/blur` 由 JS 写入的 `--coll-p∈[0,1]` 驱动（`p=scrollTop/24`，rAF 节流），白底 `linear-gradient` 向下淡出 + `mask-image` 底部渐隐消硬边。**不给 backdrop-filter/opacity 加 transition**（值本身逐帧变）。
- 采纳关键点：玻璃带不能直接放父元素（`.chips` 是 flex，伪元素 absolute 才不会成为 flex item；且必须 `z-index:-1` 否则盖住 chips）。
- 用 agent-browser 实测（`localhost:8099`，`NO_PROXY=localhost`）：scrollTop=0 时玻璃透明、chips 干净；滚动后玻璃带随滚动渐显、底部渐隐无缝。截图 `/tmp/tm-coll-top.png`、`/tmp/tm-coll-scrolled.png`。环境里 `playwright-cli` 未装，`agent-browser 0.27.0` 已装可直接用（macOS 本机）。
- 改动文件：`web/css/components.css`、`web/js/ui.js`；node --check 通过。

### 筛选条再次修订（修掉顶部硬边「缝」与发白）
- 用户反馈「还是有问题」。对其截图（2650×128）做像素分析：带子顶部亮度 247（近纯白）→ 发白；第 23 行处亮度由 ~179 突跳到 247 → 一条硬边「缝」。
- 根因（浏览器实测 `getBoundingClientRect`）：桌面端 `.main__scroll` 有 `padding-top:20px`，sticky 的 `#tm-coll-filter` 顶在**内容盒**上（`filterRect.top=20` 而 `scrollRect.top=0`）→ 上方露出 20px 未模糊内容；再叠加 `rgba(255,255,255,.92)` 白底，就成了一片白 + 硬边。
- 修法：① `--coll-gap:20px` + `::before { top: -20px }` 让玻璃带向上多铺 20px 盖住缝；② **彻底去掉白底**（`background:none`），只留 `backdrop-filter: blur(calc(--coll-p*12px))` + `mask-image` 两端渐隐（0%→20% 渐入、80%→100% 渐隐）；③ 窄屏 `@media(max-width:980px)`：此处 `.main__scroll` 变 `overflow:visible` + 整页滚动、侧栏成吸顶横条，故筛选条改 `position:static` 回到普通流（避免与侧栏打架，也避免 -22px 出血在 14px padding 下横向溢出）。
- 实测：桌面 1440 顶部亮度曲线平滑无跳变、`::before` `background:none`/`blur(12px)`；窄屏 820 无横向溢出（docW 809 ≤ 820）。截图 `/tmp/fix2.png`、`/tmp/fix2-narrow.png`。
- 注：当前是**纯模糊无白色**。若之后想要更明显的「玻璃感」，可给 `::before` 加很淡的白（如 0.25）即可。

### 筛选条第三次修订（缝仍在：底部模糊→清晰的过渡线）
- 用户反馈「感觉还是有缝」。前两轮已修掉：①白底发白、②顶部 20px 缝。这次的缝在**玻璃带下沿**——模糊与下方清晰内容的交界。
- 用 agent-browser（8099）注入统一竖向条纹复现，PIL 逐行算横向 std 当「锐度代理」定位：旧 mask `0%(清)→20%(满)→80%(满)→100%(清)` 把模糊在底部 20%（约 16px） abrupt 收口到 0，细节密集的卡片下仍被读成一条线。
- 修法：把 mask 改成**长缓坡归零**——`0% 0 → 14% .5 → 38% 1 → 46% 1 → 100% 0`，即模糊在 chips 上沿附近最强（内容已塞进不透明 chips 背后、被盖住），向下用约 46%→100%（≈40px）一路平滑减到 0，玻璃带下沿与清晰内容「零不连续」咬合。
- 实测（filter bar 视口 y=20→80，玻璃带 y=0→80）：下沿 y=50→80 模糊 1.0→0.0 跨 ~30px 渐变，到 y=80 恰为 0，与下方 sharp(stdX=110) 完全连续；顶部 y=0→20 也平滑渐入。无单行 >12 的硬跳变 → 无硬边。
- 仅改 `web/css/components.css` 的 `#tm-coll-filter::before` mask（纯 CSS，无 JS 改动）。

### 足迹年轮（stats 堆叠柱状图）样式优化
- 用户反馈统计页「足迹年轮」样式太丑。定位到的廉价感来源：① 段与段之间 `inset 0 1px 0 rgba(255,255,255,.6)` 生硬白色发丝线；② 纯平涂色块、无立体感；③ 柱子过窄/过宽（flex:1 无上限，年份少时变成巨块、多时变铅笔条）；④ 数值标签默认隐藏（仅 hover/选中显），静止时一片空。
- 改法（贴合既有 warm/圆角/主色设计语言）：
  1. 去掉白描边，每段改加「自上而下微高光」渐变 `linear-gradient(180deg, rgba(255,255,255,.2), transparent 58%)`——既出立体感又自然分隔相邻段（segments 内联 `background`→`background-color`，好让 CSS 渐变叠在上面）。
  2. 柱子 `max-width:46px` + 容器 `justify-content:center`：年份少时居中成舒适宽条、多时自然收窄填满；标签同步 `max-width:46px` 保证一一对齐。
  3. 数值标签常驻（去掉 `opacity:0`），静止 `ink-2`、hover/选中点亮成主色。
  4. 年均虚线改用柔化主色 `rgba(124,156,195,.55)`，标签改 `primary-soft` 胶囊；选中年份下沿下划线居中加粗；新增**选中年份标签同步高亮**（`.years__x.is-active`）。
- 改动文件：`web/css/components.css`（`.years` 整段）、`web/js/stats.js`（seg 内联 `background-color` + `bindYearFilter` 里 `labels[i]` 同步 `is-active`）。
- 验证：agent-browser 在 8099 注入 9 年合成数据截图，PIL 确认两种类型色柱已渲染；computed style 确认 cap opacity=1、seg 含 gradient、柱宽封顶 46 且整组居中；真实点击路径确认 bar+label 同时 is-active、其余 dim、详情渲染。node --check 通过。截图 `/tmp/stats_years.png`。
